# SkillSwap Landing Page

This package contains 3 versions of the same landing page based on the uploaded reference:
1. React + Vite
2. Angular
3. Node.js + Express

The hero image was cropped from the supplied reference screenshot so the page visually matches it.

## React
Open a terminal in `react`:
```bash
npm install
npm run dev
```
Then open the localhost address shown by Vite.

## Angular
Open a terminal in `angular`:
```bash
npm install
npm start
```
Then open the localhost address shown by Angular.

## Node.js
Open a terminal in `node`:
```bash
npm install
npm start
```
Then open:
http://localhost:3000

## If `npm` does not work on Windows
Try:
```bash
npm.cmd install
npm.cmd run dev
```
For Angular:
```bash
npm.cmd install
npm.cmd start
```
For Node:
```bash
npm.cmd install
npm.cmd start
```

If `node` itself is not recognized, install Node.js LTS and restart VS Code.
